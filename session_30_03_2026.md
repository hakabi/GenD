## 4. VS Code draw.io Extension Troubleshooting (Bug Resolution)
**The Problem:**
Upon saving the generated XML file, the VS Code draw.io extension threw a fatal error: `Unable to read file 'd:\source\GenD\BA skill\workflow-diagram.drawio' (Error: Unable to resolve nonexistent file)`.

**Diagnosis & Root Causes:**
1. **Path/Spacing Bug:** The underlying draw.io extension struggles to recognize paths that contain spaces (`BA skill`) when file changes are injected dynamically via external systems or terminal scripts rather than the visual editor itself.
2. **Caching Issues:** The internal extension cache became corrupted and failed to refresh the local state to match the system's file state.
3. **HTML Node Encoding:** Draw.io extension engines sometimes crash when rendering poorly escaped or complex HTML `<br/>` tags inside programmatic label inserts.

**Resolution Steps:**
1. Rewrote the shape labels to use strict XML plain-text newline variables (`&#xa;`) instead of HTML formatting tags.
2. Renamed the file to `qa-workflow.drawio` and saved it to the root `GenD/` folder—completely bypassing the folder space bug and clearing the extension's rendering cache.
3. Once the user verified that parsing was successful and the visual graph rendered securely in VS Code, we safely migrated the `qa-workflow.drawio` file back into its permanent home inside `BA skill\`.
