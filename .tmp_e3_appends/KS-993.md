### Acceptance criteria (BDD, v1.4)

_Scenario 1 — Happy path (matrix completeness)_

* **Given** baselines and a configured client for agent A
* **When** **Happy path** column is executed for rows **5.1–5.7**
* **Then** each non–**n/a** cell is **P** or **S** with rationale; logs meet guide section 8

_Scenario 2 — Error path_

* **Given** the same matrix
* **When** **Invalid input** and **Unauthorized user** columns run
* **Then** **P** only on correct rejection/scoping—else **F** with defect

_Scenario 3 — Edge case_

* **Given** agent B and network/large-data fixtures
* **When** remaining columns execute for agent B
* **Then** cross-agent differences are summarized
