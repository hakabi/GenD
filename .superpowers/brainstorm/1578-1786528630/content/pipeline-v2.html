What moved, and why

① Navigation now has labels and groups

My first version used a 52px icon-only rail. That's a known discoverability failure — icon-only nav forces users to guess or hover. Now: icon + label, split into Test operations and Insight, with a red count badge on Requests so failures pull you back even from another page.

② Session became a real control

Today it's a full-width strip of cryptic text across the top of the page — costing a whole band of vertical space for something you change once a week. It moves into the sidebar as a small card with a plain-language label ("Login session"), the filename, when it was saved, and one Change action. Your review's C1 note, solved by relocation.

③ Page header holds one job

Title, live count, refresh state, and exactly one primary button. The old page split this across three separate bands (title block, Show N + Refresh, then session). One row now.

④ Status tiles are the filter

The single biggest rearrangement. Before, a health bar and two dropdowns competed for the same job. Now one row of tiles answers "what's the state of things?" and filters when clicked — Failed is active here. Both native <select> boxes disappear. The fifth tile surfaces AI fallbacks, which is invisible in today's UI (theme T3 in your review).

⑤ Queue rows got a fixed reading order

Every row now reads the same way: status icon → real title (wrapping, not truncated) → status + ID → author, time, case count. Status arrives through three channels — icon shape, colour, and the word — so it survives colourblindness and greyscale printing. Numbers are tabular so times and counts line up down the column.

⑥ Tabs came back, under a sticky header

My first C draft quietly dropped Info / Execution / History. They're restored — but the title, status, ID, duration and the two actions stay pinned above them, so you always know which request you're reading and can Retry without scrolling back up.

⑦ One story, top to bottom

Lifecycle (where it got to) → failure callout (what broke, expected vs found, artifact links) → steps (the detail). Each is a distinct card with its own header instead of one undifferentiated wall. And it's one scroll region — down from four independent scrollbars today, which was the "doesn't run smooth" feeling.
