Same page, same real content (request #79c94116, the four steps ending in the failed pill check, session aloha-auth.json), so you can compare like for like. D uses the purple → aqua gradient you asked for. Directions A, B and C are on the other link. Click any that appeal — multi-select is on.

D

Aurora — gradient purple → aqua, dark premium

The modern-SaaS look you asked for. Violet #7C3AED flowing into aqua #22D3EE, on a deep navy base with a soft aurora glow behind the chrome. The gradient is used with discipline — brand mark, primary button, active nav, progress rails, selected row — and never behind body text, which is the usual way this style fails an accessibility check.

CharacterPremium, current, distinctly 2026. The one that looks least like an internal tool and most like a product you'd pay for.
ColourViolet → aqua gradient on a deep navy base. Status keeps its own semantic set so the gradient never has to mean "pass" or "fail".
Watch outThe style database flags gradient UIs for text contrast. Rule to write into the spec: gradients on chrome and accents only, never behind reading text. Also dark-first — the light variant needs designing deliberately, not auto-inverting.
Dev costMedium. Gradient tokens, glow layers and a full second theme. More CSS than A–C but no new components.
E

Bold Ops — neo-brutalist, high contrast, impossible to misread

The opposite bet from Aurora. No gradients, no soft shadows, no rounded corners — 2px black rules, flat blocks of colour, heavy uppercase type and hard offset shadows. Scores WCAG AAA almost by construction, and a failed run is visible from across the room.

F

Frosted — glassmorphism, light and airy

Translucent panels floating over a soft indigo-to-teal wash, with real background blur. Apple-adjacent, calm, and depth comes from layering rather than borders. The quietest of the eight while still looking clearly modern.

G

Swiss Data — typographic, hairline grid, one accent

Design by removal. Pure white, black text, 1px rules, zero rounded corners, one red accent, and typography doing all the hierarchy work. It's the densest of the eight and the only one that scores WCAG AAA out of the box.

H

Bento — modular cards, dashboard-first

The page stops being "list plus detail" and becomes a grid of independent modules — health, queue, lifecycle, failure, AI usage — each in its own rounded tile. Currently fashionable, and genuinely useful here because tiles can be reordered per role: QA leads with the queue, a PO leads with health.

All eight, at a glance

A Console · dark, dense, engineer-first  —  B Calm Workspace · light, editorial, newcomer-friendly  —  C Pipeline · status is the interface  —  D Aurora · purple→aqua gradient, premium  —  E Bold Ops · brutalist, unmissable  —  F Frosted · glass, soft, calm  —  G Swiss Data · typographic, AAA, timeless  —  H Bento · modular dashboard.

If the goal is "modern" specifically, the shortlist is D and F. D is the bolder, more memorable of the two and the one that reads as 2026; F is the safer version of the same instinct. My own pick stands: C's structure with D's surface — the lifecycle-first arrangement you already approved, wearing the gradient. Say the word and I'll build that hybrid as a single screen.
