Design notes

Placement — inside the QUEUE header, above the filters, so it summarises the list it sits on.
Only in-flight states — running · queued · awaiting review. Finished states (successful / failed / duplicate / rejected) live in the list + filter, not here.
Clickable = filter — each count applies the matching status filter, reusing the existing "All statuses" control.
Respects the creator filter — with "My requests" on it shows your in-flight jobs; the "awaiting your review" portion stays highlighted even in "All requests".
Live, not jarring — counts update in place, no full-page refresh.
