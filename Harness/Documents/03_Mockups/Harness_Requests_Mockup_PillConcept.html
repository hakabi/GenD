The "Created by" pill — concept notes

◆One control, two speeds — one-tap Mine / Anyone segments for the 80% case, plus a caret to pick a specific user. Faster than opening a dropdown and selecting yourself.
◆Reads as a filter, not a menu — the active segment is highlighted, so the current view ("mine" vs "everyone") is visible at a glance without opening anything.
◆Sits with the other filters — same row as "All statuses", search, and the date filter, so all scoping controls live together above the queue.
This is a styling exploration only; it does not change the shipped "All requests" dropdown or any QG-141 scope.
