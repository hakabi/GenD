Why this matches the functions

Split the axes — "what to test" (Single / New / Existing / Bug) is separated from "create only vs create + run", so the documented Execute Feature function finally has a visible control.
A contextual rule for every mode — dedupe (Single), grouped cases (New feature), regression scope (Existing), and the "expected to fail on first run" rule (Bug ticket) each appear when that mode is selected.
Labels reconciled — UI wording lines up with the function names so the team and the docs speak the same language.
