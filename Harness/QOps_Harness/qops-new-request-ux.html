QOps Harness UX revision prototype

New request flow

Chat-first parameters, then case review.

Revised New Request dialog: converse to fill fields, edit directly anytime, then review single or multiple test cases before processing.

Flow

1
New Request — chat + parameters User describes the test in chat; request mode, flow text, and session file update live. Fields are also directly editable.
2
OK → proposed test cases Single-case mode: update one case. Multi-case mode: list + CRUD before confirm.
3
Reopen from run queue Click any past run to return to the case review screen with saved state.
